Formation : Le Whisper Number

Le "Whisper Number" est l'estimation non-officielle des bénéfices d'une entreprise qui circule parmi les traders pro, souvent plus élevée que le consensus publié par les analystes. Si NVIDIA publie des résultats en ligne avec le consensus mais sous le "Whisper Number", l'action peut chuter malgré un "beat" officiel.
