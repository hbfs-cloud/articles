What Is This?

Market Watch publishes a daily watchlist of A+ scanner picks at /mcp/watchlist.json — a machine-readable JSON endpoint updated every trading day at 23:00 UTC.

Any AI coding agent — Claude Code, Cursor, Gemini CLI, Windsurf, or even ChatGPT — can fetch this data and act on it. Combined with a pre-built workflow configuration (a CLAUDE.md prompt file), your AI becomes a fully autonomous trading desk: scanning markets, analyzing setups, generating alerts, and producing institutional-grade reports.

How it works in practice

You point your AI agent at the Market Watch watchlist. The agent reads the current market regime, VIX level, and 10 curated A+ picks with precise entry/stop/target levels. Then it runs analysis, monitors conditions, and alerts you when something triggers. No coding required — just a prompt file.

Watchlist API

The watchlist is a static JSON file served at a predictable URL. It is not a REST API — no authentication, no rate limits, no API keys. Just an HTTP GET request.

Endpoint
GET https://articles.market-watch.xyz/mcp/watchlist.json

Update Schedule

  • Monday–Friday: Updated at 23:00 UTC after the scanner completes
  • Weekends: Friday's watchlist remains active (crypto picks may update)
  • The next_update field tells your agent when to check again

JSON Schema

watchlist.json
{
  "updated": "2026-03-06T23:00:00Z",     // Last update timestamp (ISO 8601)
  "source": "Market Watch Scanner",       // Data source identifier
  "url": "https://articles.market-watch.xyz/scanner/",
  "regime": "EARLY RISK-OFF",             // Market regime (see below)
  "vix": 22.5,                            // CBOE VIX level
  "dxy": 104.2,                           // US Dollar Index
  "us10y": 4.28,                          // US 10Y Treasury yield
  "spx": 5740,                            // S&P 500 level
  "fear_greed": 38,                       // CNN Fear & Greed Index (0-100)
  "picks": [                              // Array of 10 A+ setups
    {
      "ticker": "GLD",                    // Symbol
      "name": "SPDR Gold Shares",         // Full name
      "strategy": "Momentum Continuation",// Strategy type
      "entry": 236.00,                    // Entry price zone
      "stop": 228.50,                     // Stop loss level
      "tp1": 245.00,                      // Target price 1
      "tp2": 255.00,                      // Target price 2
      "rr": "1:2.5",                      // Risk/Reward ratio
      "score": 94,                        // Composite score (0-100)
      "region": "ETF",                    // US | EU | APAC | ETF | Crypto
      "tags": ["commodity", "gold"],      // Thematic tags
      "catalyst": "Iran tensions + ..."   // Key catalyst
    }
  ],
  "alerts": {                             // Market-level alerts
    "regime_change": false,               // Regime shifted since last update
    "vix_elevated": true,                 // VIX above 20
    "earnings_today": ["AVGO", "COST"],   // Tickers reporting today
    "macro_events": ["NFP 8:30 AM ET"]    // Key economic events
  },
  "next_update": "2026-03-07T23:00:00Z"  // When to check again
}

Free & Open Source — No API keys required. Uses Yahoo Finance public endpoints and Binance public API. All data stays local on your machine.

FAQ

Is the watchlist free?

Yes. The /mcp/watchlist.json endpoint is free and open. No API key, no subscription, no rate limit. It is a static JSON file served via GitHub Pages.

How often is the data updated?

Every trading day (Monday–Friday) at 23:00 UTC, after the Market Watch scanner completes its analysis. The next_update field in the JSON tells your agent exactly when to check again.

Do I need the MarketWatch Gateway MCP?

No. The static watchlist works standalone — your agent just needs to fetch a URL. However, if you want real-time data (live quotes, options chains, intraday bars, technicals), the MCP Gateway adds 58 data types via a direct connection. It is available for Claude Code and other MCP-compatible tools.

Can I use this with ChatGPT?

Yes. Paste the watchlist JSON into the conversation (or use the browsing feature to fetch the URL), along with the workflow prompt as a system message. It works with any LLM that can parse JSON.

What is the difference between the watchlist and the full scanner?

The full scanner page is a human-readable HTML report with charts, technical analysis, and detailed commentary. The watchlist.json is the machine-readable extract — same 10 picks, structured for programmatic consumption.

Is this financial advice?

No. Market Watch provides data and analysis for educational purposes. The watchlist, scanner picks, and workflows are not financial advice. Always do your own due diligence. Past scanner performance does not guarantee future results. See our full scanner retrospectives for historical accuracy data.
