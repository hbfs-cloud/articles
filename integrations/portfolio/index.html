Portfolio Replication

Free JSON endpoints to replicate the scanner portfolio. Updated every trading session (~23:00 UTC weekdays).

Live No auth 4 endpoints + RSS Nightly refresh

Quick Start

1

Fetch signals

Call /portfolio/v1/signals.json after each evening scan to get the latest picks with entry, stop, and target levels.

2

Track positions

Use /portfolio/v1/positions.json to see current open positions with live P&L, days remaining, and status.

3

Replicate

Equal-weight allocation (25% per position, 4 slots). Follow the entry range, set stop and TP as indicated. Close after 5 trading days max.

Endpoints

File URL Description Status
signals.json /portfolio/v1/signals.json Latest scanner signals — score, strategy, entry price, scan date Live
positions.json /portfolio/v1/positions.json Open positions with P&L, stop, TP1/TP2, days remaining, status Live
trades.json /portfolio/v1/trades.json Full closed-trade history — P&L%, hold days, exit reason Live
equity.json /portfolio/v1/equity.json Equity curve + backtest stats (Sharpe, Calmar, win rate, drawdown) Live
feed.xml /portfolio/v1/feed.xml RSS 2.0 — last 20 scanner publications Live

Examples

JavaScript — open positions

const { openPositions, updatedAt } = await fetch( 'https://articles.market-watch.xyz/portfolio/v1/positions.json' ).then(r => r.json()); openPositions.forEach(p => { console.log(p.ticker, p.return_pct + '%', p.status_label); });

JavaScript — latest signals

const { signals, latestScanDate } = await fetch( 'https://articles.market-watch.xyz/portfolio/v1/signals.json' ).then(r => r.json()); signals.forEach(s => console.log(s.ticker, s.score, s.strategy));

Python — equity and backtest stats

import requests BASE = "https://articles.market-watch.xyz" equity = requests.get(f"{BASE}/portfolio/v1/equity.json").json() print(f"Win rate: {equity['stats']['winRate']}%") print(f"Sharpe: {equity['stats']['sharpe']}") print(f"Return: {equity['stats']['returnTotal']}%") # Trade history trades = requests.get(f"{BASE}/portfolio/v1/trades.json").json() wins = [t for t in trades["trades"] if t["pnlPct"] > 0] print(f"Wins: {len(wins)} / {len(trades['trades'])}")

curl

curl -s https://articles.market-watch.xyz/portfolio/v1/signals.json | jq .signals curl -s https://articles.market-watch.xyz/portfolio/v1/positions.json | jq '.openPositions[] | {ticker, return_pct, status_label}' curl -s https://articles.market-watch.xyz/portfolio/v1/equity.json | jq .stats
