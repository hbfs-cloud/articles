Examples

JavaScript — open positions

// 2026-03-31T12:22 — fetch current open positions const res = await fetch('https://articles.market-watch.xyz/portfolio/v1/positions.json'); const { openPositions, updatedAt } = await res.json(); // updatedAt: "2026-03-31T12:22:46.024Z" // openPositions: // AGRO: +19.61% (En route TP1) // XLE: +10.15% (En route TP1) // DVN: +8.46% (En route TP1) // AXTI: +8.16% (En route TP1) openPositions.forEach(pos => { console.log(pos.ticker, pos.return_pct + '%', pos.status_label); });

JavaScript — latest signals

// 2026-03-31 — tonight's scan signals const { signalsByMode, latestScanDate } = await fetch( 'https://articles.market-watch.xyz/portfolio/v1/signals.json' ).then(r => r.json()); // latestScanDate: "2026-03-31" // BTU: score=94, momentum const signals = signalsByMode['calmar']; signals.forEach(s => console.log(s.ticker, s.score, s.strategy));

Python — equity and backtest stats

import requests BASE = "https://articles.market-watch.xyz" # 2026-03-31 — equity curve and backtest stats equity = requests.get(f"{BASE}/portfolio/v1/equity.json").json() stats = equity["equity"]["calmar"]["stats"] print(f"Win rate: {stats['winRate']}%") # 70% print(f"Sharpe: {stats['sharpe']}") # 192.5 print(f"Return: {stats['returnTotal']}%") # 3.85% # Closed trades trades = requests.get(f"{BASE}/portfolio/v1/trades.json").json() closed = trades["tradesByMode"]["calmar"] wins = [t for t in closed if t["pnlPct"] > 0] print(f"Wins: {len(wins)} / {len(closed)}")
