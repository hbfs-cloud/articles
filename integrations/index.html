Integrations & API

Static JSON and RSS endpoints for portfolio replication across 3 scanner modes. No authentication, no rate limits — updated every trading session.

Live endpoints No auth 3 modes JSON & RSS Updated nightly

Quick Start

1

Pick a mode

Choose Growth, Balanced, or Conservative depending on your risk tolerance and holding horizon.

2

Fetch the endpoint

Call /api/v1/signals.json or /api/v1/positions.json to get live signals and open positions.

3

Replicate the portfolio

Use entry, stop, and TP levels from positions.json to size positions. Equal-weight by default.

Mode ID mapping note
In trades.json the source key "sharpe" maps to mode "zero" (Conservative). In all other endpoints the canonical IDs growth, calmar, and zero are used consistently.

Code Examples

JavaScript (fetch)

// Fetch current open positions const res = await fetch('/api/v1/positions.json'); const data = await res.json(); // data.openPositions is an array of all open positions data.openPositions.forEach(pos => { console.log(pos.ticker, pos.return_pct + '%', pos.status_label); });

JavaScript — signals by mode

const { signalsByMode } = await fetch('/api/v1/signals.json').then(r => r.json()); // Latest signals for the Balanced mode const balanced = signalsByMode['calmar']; balanced.forEach(s => console.log(s.ticker, s.score, s.strategy));

Python (requests)

import requests BASE = "https://articles.market-watch.xyz" # Equity curves and backtest stats equity = requests.get(f"{BASE}/api/v1/equity.json").json() growth_stats = equity["equity"]["growth"]["stats"] print(f"Growth win rate: {growth_stats['winRate']}%") print(f"Growth Sharpe: {growth_stats['sharpe']}") # All closed trades for the Conservative mode trades = requests.get(f"{BASE}/api/v1/trades.json").json() conservative = trades["tradesByMode"]["zero"] wins = [t for t in conservative if t["pnlPct"] > 0] print(f"Conservative wins: {len(wins)} / {len(conservative)}")

Rate Limits & Usage

These are static files served via GitHub Pages — there are no server-side rate limits.
  • Files are regenerated once per trading day after the evening scan (~23:00 UTC weekdays).
  • Polling more than once per minute is wasteful — the data changes at most once a day.
  • For real-time prices, use the MCP Gateway tools (QueryData, GetInstruments) which proxy live market data.
  • CORS headers are served by GitHub Pages. You can fetch these endpoints client-side from any origin.
