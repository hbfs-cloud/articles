Business Overview

Datadog sells usage-based observability and security subscriptions across infrastructure monitoring, logs, application performance, digital experience and cloud security. Revenue expands as customers send more telemetry and adopt additional products. Customers above $100,000 ARR test whether platform consolidation is broadening spend.

Generative-AI systems increase model calls, distributed services, traces, token metrics and security events. LLM Observability can link quality, latency and cost to application behavior. The benefit is not automatic because customers can sample logs, shorten retention or route data to cheaper tools when ingestion bills rise.

Datadog loses pricing power if hyperscalers bundle adequate native monitoring or OpenTelemetry lowers switching costs. A 79.5% gross margin funds investment, but near-zero GAAP operating margin means compensation absorbs much of the accounting profit. Growth must remain broad across products and large customers.

Unit economics depend on ingesting more valuable telemetry without letting storage and processing costs outrun price. Security cross-sell improves the mix only when customers consolidate spend instead of adding discounted modules to an unchanged observability bill.
