Comment appliquer ce mode

Méthodologie du Sweep

Grid Search Exhaustif

98 000 combinaisons testées sur 8 dimensions : taille portfolio (1-20), signaux/scan (1-5), score min (0-95), horizon (5-30j), 5 filtres stratégie, 4 modes rotation, partial TP, trailing stop.

Simulation Réaliste

Entrée au prix d'ouverture réel J+1 (Yahoo Finance OHLCV). Stop/TP ajustés en R-multiple depuis l'entrée réelle. SL vérifié avant TP sur chaque barre (conservateur).

Walk-Forward Validation

Split 70/30 : 15 scans in-sample pour optimiser, 6 scans out-of-sample pour valider. Dégradation mesurée sur chaque combo.

Anti-Overfitting

Minimum 8 trades par combo pour éviter le cherry-picking. Métriques multiples (Sharpe, Calmar, Sortino) pour éviter l'optimisation sur un seul critère.

Walk-Forward — Dégradation Out-of-Sample

La dégradation mesure combien le Sharpe baisse entre l'échantillon d'entraînement et le test. Avec seulement 23 scans, une dégradation élevée est attendue. Les résultats seront réévalués quand on atteindra 50+ scans.

Comment relancer le sweep

Le sweep est exécuté manuellement ou via le cron audit-systeme du dimanche. Pour le relancer :

cd /home/ci/projects/articles
node tools/sweep.js          # Full (98k combos, ~5 min)
node tools/sweep.js --quick  # Quick (720 combos, ~30s)

Les résultats sont sauvegardés dans data/backtest-results.json et data/portfolio-history.json.
