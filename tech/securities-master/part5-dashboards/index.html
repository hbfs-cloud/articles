The Model Context Protocol (MCP)

The Python Clustering Engine and the Go Strategy Scanner from previous parts produce incredible subsets of data (e.g., the top 50 breakout candidates globally). To empower our autonomous AI Finance Agent, we expose these curated PostgreSQL Gold Marts via an MCP Tool Server.

// mcp_server.go
func RunAutoScreenerTool(intent string) ([]Candidate, error) {
    // 1. Detect market regime directly from our Gold Marts
    regime := DetectMarketRegimeSQL()
    
    // 2. Fetch the top K pre-calculated momentum strategies
    return db.Query(`
        SELECT symbol, realized_vol_20d, trend_regime 
        FROM gold.mart_strategy_universe 
        WHERE trend_regime = $1 
        ORDER BY adv_20d_usd DESC LIMIT 10
    `, regime)
}
// The LLM perfectly comprehends the filtered output and designs a balanced portfolio allocation.

BI-as-Code with Evidence.dev

While the AI Agent operates autonomously, human Portfolio Managers demand oversight. We use Evidence.dev to securely map Markdown directly to our `gold.mart_strategy_universe` table. Because it's "BI-as-Code," all dashboards are version-controlled alongside the Python and Go source code.
