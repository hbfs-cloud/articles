La Mort du "Copier-Coller"

Discuter en format texte avec une IA, c'était le standard en 2023. Anthropic a littéralement "cassé" l'interface de conversation pour vous offrir : les Artifacts. L'IA produit dorénavant ses applications, graphiques et lignes de code directement interactives sous vos yeux.

Imaginez le cauchemar logistique d'une banque de détail (une Retail Bank) il y a encore un mois : le directeur des prêts immobiliers voulait une nouvelle calculette de taux hypothécaires dynamique pour ses courtiers.

Le processus infernal classique : Le directeur crée un ticket sur Jira (logiciel de gestion). Il décrit ce qu'il veut pendant 2h en texte. Un designer passe 3 jours sur une maquette (Figma). La maquette est validée par le manager. Un développeur React prend le relais, code pendant 2 semaines. Le testeur vérifie, renvoie pour un changement de couleur. Bilan : 3 à 4 semaines de travail, des dizaines de milliers d'euros engloutis.

Et si on utilisait le rudimentaire ChatGPT pour ce problème ? Le directeur demanderait à ChatGPT de coder la calculatrice. ChatGPT écrirait 400 lignes de texte technique incompréhensible pour le directeur. Ce dernier ne pourrait rien tester lui-même et devrait faire appel à un développeur pour "copier-coller" et installer le code. La friction restait énorme.

L'Invention d'Artifact : L'Écran Divisé

C'est ici qu'Anthropic a bouleversé l'industrie des logiciels avec les Artifacts. Ils n'ont pas seulement amélioré le "cerveau" de l'IA, ils ont changé l'interface homme-machine.

Quand une réponse contient du code, un graphique, ou la structure d'un site web interactif, la fenêtre de chat se coupe soudainement en deux. À gauche, la discussion textuelle (le prompt). À droite, l'IA compile et héberge instantanément l'application interactive finie dans votre propre navigateur.

ZONE DE CHAT
Utilisateur : Crée-moi une "Calculatrice Hipothécaire" pour notre équipe. Je veux un taux de 4.8%. Fais-en un widget React.
Claude : Bien sûr ! J'écris le code React. Je l'exécute pour vous dans l'Artifact sur la droite ➡️. Vous pouvez même cliquer dessus !
Utilisateur : Change le bouton en violet pour coller à la charte et ajoute un liseré gris sombre.

Le Bilan de la Révolution Artifact

Dans notre cas de la banque de détail de tout à l'heure, le temps de développement est passé de 3 semaines à environ 2 minutes.

Le directeur saisit sa demande. Il voit le résultat à droite fonctionner immédiatement. S'il n'aime pas un bouton, il dit "change la couleur de la police", l'IA corrige le code, et l'appli sur la droite change de design en temps-réel. C'est l'essence du No-Code radicalisé et instantané.

Une fois satisfait, il peut exporter l'Artifact final et le donner à son équipe IT pour l'intégrer au système central.

Claude Code : Le Co-Pilote des Ingénieurs (Fintech)

Si les Artifacts sont la solution ultime pour les managers de produit, les analystes ou les commerciaux, qu'en est-il du "cœur du réacteur" de toute entreprise : les développeurs et les ingénieurs d'infrastructure ?

Historiquement, 30% du temps d'un développeur est monopolisé par des "tâches ingrates" et à faible valeur ajoutée : mettre à jour des dizaines de librairies vétustes, réparer des milliers de petites erreurs (les deprecations de code) liées à de nouvelles versions, ou écrire d'interminables fichiers de tests pour vérifier que le code de paiement fonctionne.

Pendant quelques mois, GitHub Copilot régnait en maître en écrivant quelques lignes de code par-ci par-là. Mais Anthropic vient d'annoncer Claude Code. Ce n'est plus une application d'interface où l'on discute. Claude Code est un agent terminal qui possède virtuellement tout l'ordinateur du développeur. L'humain se transforme en "Chef de Chantier".

Une Autonomie Totale dans la Fintech

Prenons l'exemple d'une équipe de développement chez Stripe ou Block. Ils doivent migrer un ancien module qui traite les Cartes de Crédit (écrit en Node.js 14) vers Node.js 20, ce qui casse la moitié du programme.

Avant, un ingénieur senior devait chercher chaque erreur à la main pendant une semaine.

Avec Claude Code : L'ingénieur tape la phrase suivante dans son terminal terminal et laisse la magie opérer :

$ claude "Mets à jour tout le dossier de paiements vers Node 20. Lis chaque fichier pour trouver les librairies obsolètes. Corrige-les, puis lance la commande 'npm test' toute seule. Si des tests échouent, corrige tes erreurs jusqu'à ce que tout soit vert au terminal."

Voici l'innovation cruciale par rapport au Copier-Coller : Claude Code va de lui-même (comme un agent) observer la structure de vos dossiers de fichiers. Il va "ouvrir" tel fichier en mode édition informatiquement, supprimer le mauvais code, et écrire le nouveau. Ensuite, l'Agent lance lui-même le test unitaire sur la machine. S'il voit l'erreur rouge à l'écran, il réfléchit en boucle, retourne éditer le fichier, relance le test, jusqu'à avoir résolu le problème. Puis, il s'arrête, prêt pour la validation finale du Développeur Humain. L'ingénieur informatique senior valide le travail avec 2 ans d'expérience qu'une machine vient de réaliser dans la journée sans assistance humaine.

Pourquoi cela affole Wall Street ? Les gains de productivité pour les milliers d'ingénieurs des mégabanques (JPMorgan embauche plus de développeurs que Google) ne se comptent plus en pourcentages marginaux. La vélocité double, avec le même nombre d'employés, sur le logiciel le plus complexe que la planète héberge financièrement.

En Synthèse

Avec les Artifacts, Anthropic a libéré les opérationnels non-techniques de l'ère du Copier-Coller en permettant à l'IA de rendre son code instantanément visuel et interactif (Dashboard, UI). Avec Claude Code, Anthropic libère l'ingénieur en transformant les ordinateurs en moteurs autonomes capables de compiler et d'exécuter l'infrastructure lourde.

Prochaine Étape : Quitter l'ère du Texte Numérique

Mais il reste un énorme pan de l'économie, presque le Dark Matter (la Matière Noire) du monde financier : les logiciels monolithiques impossibles à brancher. (Les vieux logiciels AS400, l'obscurité des systèmes de gestion des compagnies aériennes, les vieux écrans SAP d'inventaires d'usines ou le navigateur bloqué d'un fournisseur).

S'ils n'ont ni API (Moyen de connexion), ni langage moderne pour qu'une IA intervienne... Comment faire ? La seule façon dont un humain s'en sert, c'est en regardant avec ses yeux, et en utilisant une souris.

Dans la Partie 4. Agents (Computer Use), nous allons voir comment Anthropic a récemment terrorisé l'industrie de l'automatisation en dotant Claude de "bras" et "d'yeux" physiques. L'IA qui prend réellement la souris de l'ordinateur. L'automatisation Agentic RPA de classe mondiale.
