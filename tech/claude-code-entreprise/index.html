Semantic Layer + IA : L'Intelligence des Données

Le Semantic Layer est la pièce manquante entre l'IA et les données d'entreprise. Sans lui, Claude ne voit que des tables SQL brutes, des colonnes ambigües et des relations cachées. Avec lui, Claude comprend la signification métier de chaque donnée : ce qu'est le "MRR", comment calculer le "churn", quelle est la définition officielle du "revenu net".

Sans Semantic Layer, l'IA hallucine sur vos données
Un LLM connecté directement à une base SQL va inventer des jointures, confondre les métriques, mélanger les dimensions. Le Semantic Layer est le contrat entre vos données et l'IA : définitions précises, calculs validés, relations explicites.

Qu'est-ce qu'un Semantic Layer ?

Un Semantic Layer est une couche d'abstraction posée entre les données brutes (tables SQL) et les consommateurs (BI tools, LLMs, APIs). Il définit :

  • Entités : les objets métier (client, commande, produit, employé)
  • Mesures : les métriques calculées (revenu total, marge brute, NPS)
  • Dimensions : les axes d'analyse (date, segment client, région, produit)
  • Relations : les liens entre entités (client → commandes → produits)
  • Métriques dérivées : les KPIs composés (revenu par client, LTV/CAC ratio)

Définir un Semantic Model dbt

Voici un modèle sémantique complet pour le revenu d'une entreprise SaaS, défini en YAML dans votre projet dbt :

models/semantic/revenue.yml
semantic_models:
  - name: revenue
    description: "Modèle de revenu SaaS - MRR, ARR, churn"
    model: ref('fct_subscriptions')
    defaults:
      agg_time_dimension: subscription_date
    
    entities:
      - name: subscription_id
        type: primary
      - name: customer_id
        type: foreign
        expr: customer_id
      - name: plan_id
        type: foreign
        expr: plan_id
    
    measures:
      - name: total_mrr
        description: "Monthly Recurring Revenue total"
        expr: mrr_amount
        agg: sum
      - name: subscription_count
        description: "Nombre d'abonnements actifs"
        agg: count
      - name: avg_contract_value
        description: "Valeur moyenne d'un contrat"
        expr: contract_value
        agg: average
      - name: churned_mrr
        description: "MRR perdu (churn)"
        expr: "case when status = 'churned' then mrr_amount else 0 end"
        agg: sum
    
    dimensions:
      - name: customer_segment
        type: categorical
        expr: customer_segment
        description: "Segment client : startup, mid-market, enterprise"
      - name: plan_type
        type: categorical
        expr: plan_name
        description: "Type de plan : free, pro, business, enterprise"
      - name: subscription_date
        type: time
        expr: created_at
        time_granularity: day
      - name: region
        type: categorical
        expr: billing_country
        description: "Région géographique du client"

metrics:
  - name: mrr
    description: "Monthly Recurring Revenue"
    type: simple
    type_params:
      measure: total_mrr

  - name: net_mrr_retention
    description: "Net MRR Retention Rate"
    type: derived
    type_params:
      expr: "(total_mrr - churned_mrr) / total_mrr * 100"
      metrics:
        - name: total_mrr
        - name: churned_mrr

  - name: arpu
    description: "Average Revenue Per User"
    type: derived
    type_params:
      expr: "total_mrr / subscription_count"
      metrics:
        - name: total_mrr
        - name: subscription_count

  - name: ltv_estimate
    description: "Estimated Lifetime Value (MRR * avg_lifetime_months)"
    type: derived
    type_params:
      expr: "(total_mrr / subscription_count) * 24"
      metrics:
        - name: total_mrr
        - name: subscription_count

Construire un MCP Server pour le Semantic Layer

L'objectif est de créer un serveur MCP que Claude Code peut interroger en langage naturel. Le serveur traduit les questions en requêtes sémantiques, exécute via MetricFlow ou Cube.js, et retourne les données structurées.

mcp-semantic-layer/server.py
"""
MCP Server : Semantic Layer Bridge
Connecte Claude Code au dbt Semantic Layer via MetricFlow API
"""
import json
import httpx
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("semantic-layer")

METRICFLOW_URL = "http://localhost:8765/api/v1"
DBT_CLOUD_TOKEN = "dbt_cloud_token_here"

# Cache du catalogue de métriques
_metrics_catalog = None

@mcp.tool()
async def list_metrics() -> str:
    """Liste toutes les métriques disponibles dans le Semantic Layer.
    Retourne nom, description, type et dimensions disponibles."""
    global _metrics_catalog
    if _metrics_catalog is None:
        async with httpx.AsyncClient() as client:
            resp = await client.get(
                f"{METRICFLOW_URL}/metrics",
                headers={"Authorization": f"Bearer {DBT_CLOUD_TOKEN}"}
            )
            _metrics_catalog = resp.json()
    
    result = []
    for m in _metrics_catalog["metrics"]:
        result.append({
            "name": m["name"],
            "description": m["description"],
            "type": m["type"],
            "dimensions": [d["name"] for d in m.get("dimensions", [])],
            "time_grains": m.get("time_granularities", ["day", "week", "month"])
        })
    return json.dumps(result, indent=2)


@mcp.tool()
async def query_metric(
    metric_names: list[str],
    group_by: list[str] | None = None,
    time_grain: str = "month",
    time_range: str = "last_6_months",
    filters: dict | None = None,
    order_by: str | None = None,
    limit: int = 100
) -> str:
    """Interroge une ou plusieurs métriques du Semantic Layer.
    
    Args:
        metric_names: Liste des métriques (ex: ["mrr", "arpu"])
        group_by: Dimensions de regroupement (ex: ["customer_segment", "region"])
        time_grain: Granularité temporelle (day, week, month, quarter, year)
        time_range: Période (last_7_days, last_30_days, last_6_months, last_year, ytd)
        filters: Filtres optionnels (ex: {"customer_segment": "enterprise"})
        order_by: Colonne de tri (ex: "mrr DESC")
        limit: Nombre max de résultats
    
    Returns:
        Données tabulaires au format JSON avec métadonnées
    """
    payload = {
        "metrics": [{"name": m} for m in metric_names],
        "group_by": group_by or [],
        "time_grain": time_grain,
        "time_range": time_range,
        "limit": limit
    }
    if filters:
        payload["where"] = [
            {"dimension": k, "operator": "=", "value": v}
            for k, v in filters.items()
        ]
    if order_by:
        payload["order_by"] = [order_by]
    
    async with httpx.AsyncClient(timeout=30) as client:
        resp = await client.post(
            f"{METRICFLOW_URL}/query",
            json=payload,
            headers={"Authorization": f"Bearer {DBT_CLOUD_TOKEN}"}
        )
        data = resp.json()
    
    return json.dumps({
        "query": payload,
        "row_count": len(data.get("rows", [])),
        "columns": data.get("columns", []),
        "rows": data.get("rows", []),
        "sql_generated": data.get("sql", ""),
        "cache_hit": data.get("cache_hit", False)
    }, indent=2)


@mcp.tool()
async def explain_metric(metric_name: str) -> str:
    """Retourne la définition complète d'une métrique :
    formule SQL, dimensions, entités, description métier."""
    async with httpx.AsyncClient() as client:
        resp = await client.get(
            f"{METRICFLOW_URL}/metrics/{metric_name}",
            headers={"Authorization": f"Bearer {DBT_CLOUD_TOKEN}"}
        )
        metric = resp.json()
    
    return json.dumps({
        "name": metric["name"],
        "description": metric["description"],
        "type": metric["type"],
        "sql_expression": metric.get("expr", "N/A"),
        "aggregation": metric.get("agg", "N/A"),
        "base_model": metric.get("model", "N/A"),
        "dimensions": metric.get("dimensions", []),
        "filters_available": metric.get("filters", []),
        "business_definition": metric.get("meta", {}).get("business_definition", ""),
        "owner": metric.get("meta", {}).get("owner", "data-team"),
        "last_updated": metric.get("meta", {}).get("last_updated", "")
    }, indent=2)


@mcp.tool()
async def compare_periods(
    metric_name: str,
    current_period: str = "this_month",
    comparison_period: str = "last_month",
    group_by: list[str] | None = None
) -> str:
    """Compare une métrique entre deux périodes.
    Retourne les valeurs, le delta absolu et le delta en pourcentage."""
    # Query current period
    current = await _query_period(metric_name, current_period, group_by)
    previous = await _query_period(metric_name, comparison_period, group_by)
    
    comparisons = []
    for key in current:
        curr_val = current[key]
        prev_val = previous.get(key, 0)
        delta = curr_val - prev_val
        delta_pct = (delta / prev_val * 100) if prev_val != 0 else None
        comparisons.append({
            "dimension": key,
            "current": curr_val,
            "previous": prev_val,
            "delta": delta,
            "delta_percent": round(delta_pct, 2) if delta_pct else None,
            "trend": "up" if delta > 0 else "down" if delta < 0 else "flat"
        })
    
    return json.dumps({
        "metric": metric_name,
        "current_period": current_period,
        "comparison_period": comparison_period,
        "comparisons": comparisons
    }, indent=2)


if __name__ == "__main__":
    mcp.run(transport="stdio")

mcp-cubejs/server.py
"""MCP Server pour Cube.js"""
import httpx
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("cubejs")
CUBE_API = "http://localhost:4000/cubejs-api/v1"
CUBE_TOKEN = "your_cube_jwt_token"

@mcp.tool()
async def cube_query(
    measures: list[str],
    dimensions: list[str] | None = None,
    time_dimension: str | None = None,
    date_range: list[str] | None = None,
    filters: list[dict] | None = None,
    order: dict | None = None,
    limit: int = 100
) -> str:
    """Interroge l'API Cube.js avec des mesures et dimensions."""
    query = {"measures": measures, "limit": limit}
    if dimensions:
        query["dimensions"] = dimensions
    if time_dimension and date_range:
        query["timeDimensions"] = [{
            "dimension": time_dimension,
            "dateRange": date_range,
            "granularity": "month"
        }]
    if filters:
        query["filters"] = filters
    if order:
        query["order"] = order
    
    async with httpx.AsyncClient(timeout=30) as client:
        resp = await client.post(
            f"{CUBE_API}/load",
            json={"query": query},
            headers={"Authorization": CUBE_TOKEN}
        )
        return resp.text

if __name__ == "__main__":
    mcp.run(transport="stdio")
Le Semantic Layer est le Rosetta Stone
Le Semantic Layer est au LLM ce que le dictionnaire est à l'étudiant étranger. Sans lui, le modèle devine ce que signifient vos colonnes. Cette précision élimine les hallucinations sur les données.

Automatisation Comptable

La comptabilité est le candidat idéal pour l'automatisation IA : des processus répétitifs, des règles bien définies, un volume élevé de documents, et un coût d'erreur significatif. Un comptable passe en moyenne 60% de son temps sur des tâches automatisables : saisie de factures, rapprochement bancaire, classification de dépenses.

TOUJOURS un human-in-the-loop pour les écritures comptables
L'IA prépare, classe, vérifie et signale les anomalies. Un comptable valide les écritures avant comptabilisation définitive. C'est une obligation légale dans la plupart des juridictions (Code de Commerce, IFRS, US GAAP).

@mcp.tool()
async def match_purchase_order(
    vendor_name: str,
    amount: float,
    tolerance: float = 0.05
) -> str:
    """Recherche un bon de commande correspondant à la facture.
    Tolérance par défaut : 5% sur le montant."""
    async with httpx.AsyncClient() as client:
        resp = await client.get(
            f"{XERO_API}/PurchaseOrders",
            headers=headers,
            params={
                "where": f'Contact.Name=="{vendor_name}" '
                         f'AND Status=="AUTHORISED"',
                "order": "Date DESC"
            }
        )
        orders = resp.json().get("PurchaseOrders", [])
    
    matches = []
    for po in orders:
        po_amount = float(po.get("Total", 0))
        diff = abs(po_amount - amount) / po_amount if po_amount else 1
        if diff <= tolerance:
            matches.append({
                "po_number": po["PurchaseOrderNumber"],
                "amount": po_amount,
                "date": po["Date"],
                "match_confidence": round((1 - diff) * 100, 1)
            })
    
    return json.dumps({
        "vendor": vendor_name,
        "invoice_amount": amount,
        "matches_found": len(matches),
        "matches": sorted(matches, key=lambda x: x["match_confidence"], reverse=True)
    }, indent=2)


@mcp.tool()
async def detect_anomalies(invoice_data: dict) -> str:
    """Détecte les anomalies dans une facture :
    - Doublon (même numéro, même fournisseur)
    - Montant inhabituel (> 2 écarts-types de la moyenne fournisseur)
    - Date suspecte (antérieure à 90 jours)
    - TVA incorrecte (taux non standard)"""
    anomalies = []
    
    # Vérifier doublons
    async with httpx.AsyncClient() as client:
        resp = await client.get(
            f"{XERO_API}/Invoices",
            headers=headers,
            params={
                "where": f'InvoiceNumber=="{invoice_data["number"]}" '
                         f'AND Contact.Name=="{invoice_data["vendor"]}"'
            }
        )
        existing = resp.json().get("Invoices", [])
        if existing:
            anomalies.append({
                "type": "DUPLICATE",
                "severity": "HIGH",
                "message": f"Facture {invoice_data['number']} existe déjà pour {invoice_data['vendor']}"
            })
    
    # Vérifier montant
    if invoice_data.get("amount", 0) > 50000:
        anomalies.append({
            "type": "HIGH_AMOUNT",
            "severity": "MEDIUM",
            "message": f"Montant élevé ({invoice_data['amount']}€) - vérification manuelle recommandée"
        })
    
    # Vérifier date
    inv_date = datetime.strptime(invoice_data.get("date", ""), "%Y-%m-%d")
    if (datetime.now() - inv_date).days > 90:
        anomalies.append({
            "type": "OLD_INVOICE",
            "severity": "LOW",
            "message": f"Facture datée de plus de 90 jours ({invoice_data['date']})"
        })
    
    return json.dumps({
        "anomalies_count": len(anomalies),
        "anomalies": anomalies,
        "recommendation": "BLOCK" if any(a["severity"] == "HIGH" for a in anomalies) 
                         else "REVIEW" if anomalies else "OK"
    }, indent=2)


@mcp.tool()
async def bank_reconciliation(
    account_id: str,
    start_date: str,
    end_date: str
) -> str:
    """Rapprochement bancaire automatique.
    Compare les transactions bancaires aux factures et suggère les correspondances."""
    async with httpx.AsyncClient() as client:
        # Récupérer les transactions bancaires
        bank_resp = await client.get(
            f"{XERO_API}/BankTransactions",
            headers=headers,
            params={"where": f'BankAccount.AccountID==guid("{account_id}") '
                             f'AND Date>=DateTime({start_date.replace("-", ",")}) '
                             f'AND Date<=DateTime({end_date.replace("-", ",")})',
                    "order": "Date"}
        )
        transactions = bank_resp.json().get("BankTransactions", [])
        
        # Récupérer les factures en attente
        inv_resp = await client.get(
            f"{XERO_API}/Invoices",
            headers=headers,
            params={"where": 'Status=="AUTHORISED"', "order": "Date"}
        )
        invoices = inv_resp.json().get("Invoices", [])
    
    # Matching automatique
    matches = []
    unmatched_txns = []
    for txn in transactions:
        matched = False
        for inv in invoices:
            if abs(float(txn["Total"]) - float(inv["Total"])) < 0.01:
                matches.append({
                    "transaction": txn["BankTransactionID"],
                    "invoice": inv["InvoiceNumber"],
                    "amount": txn["Total"],
                    "confidence": "HIGH"
                })
                matched = True
                break
        if not matched:
            unmatched_txns.append({
                "id": txn["BankTransactionID"],
                "date": txn["Date"],
                "amount": txn["Total"],
                "reference": txn.get("Reference", "")
            })
    
    return json.dumps({
        "period": f"{start_date} to {end_date}",
        "total_transactions": len(transactions),
        "auto_matched": len(matches),
        "unmatched": len(unmatched_txns),
        "match_rate": f"{len(matches)/len(transactions)*100:.1f}%" if transactions else "0%",
        "matches": matches[:20],
        "unmatched_transactions": unmatched_txns[:20]
    }, indent=2)

- TVA à 0% : vérifier autoliquidation ou exonération

- Statut (CREATED, BLOCKED, NEEDS_REVIEW)

@mcp.tool()
async def score_lead(
    company_data: dict,
    icp_criteria: dict = None
) -> str:
    """Score un lead selon le profil client idéal (ICP).
    
    Args:
        company_data: Données enrichies de l'entreprise
        icp_criteria: Critères ICP personnalisés
    
    ICP par défaut (SaaS B2B) :
    - Taille : 50-500 employés (30 pts)
    - Secteur : Tech, Finance, Healthcare (20 pts)
    - Technologies : utilise des outils modernes (15 pts)
    - Funding : Série A+ (15 pts)
    - Géo : Europe / Amérique du Nord (10 pts)
    - Intent : signaux d'achat détectés (10 pts)
    """
    if icp_criteria is None:
        icp_criteria = {
            "employee_range": [50, 500],
            "target_industries": ["Technology", "Financial Services", "Healthcare"],
            "target_technologies": ["AWS", "Python", "React", "Kubernetes"],
            "min_funding": "Series A",
            "target_geos": ["US", "UK", "FR", "DE"]
        }
    
    score = 0
    breakdown = {}
    
    # Taille (30 pts)
    emp = company_data.get("employee_count", 0)
    if icp_criteria["employee_range"][0] <= emp <= icp_criteria["employee_range"][1]:
        score += 30
        breakdown["company_size"] = {"score": 30, "max": 30, "detail": f"{emp} employés"}
    elif emp > 0:
        size_score = max(0, 30 - abs(emp - 250) / 25)
        score += size_score
        breakdown["company_size"] = {"score": round(size_score), "max": 30, "detail": f"{emp} employés"}
    
    # Secteur (20 pts)
    industry = company_data.get("industry", "")
    if industry in icp_criteria["target_industries"]:
        score += 20
        breakdown["industry"] = {"score": 20, "max": 20, "detail": industry}
    else:
        breakdown["industry"] = {"score": 0, "max": 20, "detail": industry}
    
    # Technologies (15 pts)
    techs = set(company_data.get("technologies", []))
    target_techs = set(icp_criteria["target_technologies"])
    tech_overlap = len(techs & target_techs)
    tech_score = min(15, tech_overlap * 5)
    score += tech_score
    breakdown["technology_fit"] = {"score": tech_score, "max": 15, "detail": list(techs & target_techs)}
    
    # Géo (10 pts)
    country = company_data.get("location", {}).get("country", "")
    if country in icp_criteria["target_geos"]:
        score += 10
        breakdown["geography"] = {"score": 10, "max": 10, "detail": country}
    else:
        breakdown["geography"] = {"score": 0, "max": 10, "detail": country}
    
    tier = "A+" if score >= 85 else "A" if score >= 70 else "B" if score >= 50 else "C" if score >= 30 else "D"
    
    return json.dumps({
        "total_score": round(score),
        "tier": tier,
        "breakdown": breakdown,
        "recommendation": "HIGH_PRIORITY" if tier in ["A+", "A"] else 
                         "STANDARD" if tier == "B" else "LOW_PRIORITY"
    }, indent=2)

Détection d'anomalies intelligente

mcp-reporting/anomaly_detector.py
"""
Module de détection d'anomalies pour le reporting automatisé.
Utilise des méthodes statistiques simples + Claude pour l'interprétation.
"""
import numpy as np
from dataclasses import dataclass

@dataclass
class Anomaly:
    metric: str
    current_value: float
    expected_value: float
    deviation_percent: float
    severity: str  # LOW, MEDIUM, HIGH, CRITICAL
    direction: str  # UP, DOWN
    context: str

def detect_anomalies(
    metric_name: str,
    values: list[float],
    labels: list[str],
    threshold_sigma: float = 2.0,
    min_deviation_pct: float = 15.0
) -> list[Anomaly]:
    """Détecte les anomalies dans une série temporelle de métriques.
    
    Méthode : Z-score + seuil de déviation relative.
    Une anomalie est signalée si :
    1. Le Z-score dépasse threshold_sigma (défaut: 2.0)
    2. ET la déviation relative dépasse min_deviation_pct (défaut: 15%)
    """
    if len(values) < 4:
        return []
    
    arr = np.array(values)
    mean = np.mean(arr[:-1])  # Moyenne sans la dernière valeur
    std = np.std(arr[:-1])
    current = arr[-1]
    
    anomalies = []
    
    if std > 0:
        z_score = (current - mean) / std
        deviation_pct = abs(current - mean) / mean * 100 if mean != 0 else 0
        
        if abs(z_score) > threshold_sigma and deviation_pct > min_deviation_pct:
            severity = ("CRITICAL" if abs(z_score) > 3.5 else
                       "HIGH" if abs(z_score) > 3.0 else
                       "MEDIUM" if abs(z_score) > 2.5 else "LOW")
            
            anomalies.append(Anomaly(
                metric=metric_name,
                current_value=current,
                expected_value=round(mean, 2),
                deviation_percent=round(deviation_pct, 1),
                severity=severity,
                direction="UP" if current > mean else "DOWN",
                context=f"Z-score: {z_score:.2f}, {len(values)-1} périodes analysées"
            ))
    
    # Détection de tendance (3+ périodes consécutives en baisse/hausse)
    if len(values) >= 4:
        recent = values[-4:]
        diffs = [recent[i+1] - recent[i] for i in range(3)]
        if all(d < 0 for d in diffs):
            anomalies.append(Anomaly(
                metric=metric_name,
                current_value=current,
                expected_value=values[-4],
                deviation_percent=round(abs(current - values[-4]) / values[-4] * 100, 1) if values[-4] != 0 else 0,
                severity="MEDIUM",
                direction="DOWN",
                context="Tendance baissiere sur 4 periodes consecutives"
            ))
        elif all(d > 0 for d in diffs):
            anomalies.append(Anomaly(
                metric=metric_name,
                current_value=current,
                expected_value=values[-4],
                deviation_percent=round(abs(current - values[-4]) / values[-4] * 100, 1) if values[-4] != 0 else 0,
                severity="LOW",
                direction="UP",
                context="Tendance haussiere sur 4 periodes consecutives"
            ))
    
    return anomalies

-- Appelée dans le pipeline après chaque transformation

{% macro claude_anomaly_check(model_name, column_name, lookback_days=30) %}

WITH stats AS (
    SELECT
        AVG({{ column_name }}) as avg_val,
        STDDEV({{ column_name }}) as std_val,
        MIN({{ column_name }}) as min_val,
        MAX({{ column_name }}) as max_val,
        COUNT(*) as row_count,
        COUNT(DISTINCT {{ column_name }}) as distinct_count,
        SUM(CASE WHEN {{ column_name }} IS NULL THEN 1 ELSE 0 END) as null_count
    FROM {{ ref(model_name) }}
    WHERE created_at >= CURRENT_DATE - INTERVAL '{{ lookback_days }} days'
),
latest AS (
    SELECT
        AVG({{ column_name }}) as latest_avg,
        COUNT(*) as latest_count
    FROM {{ ref(model_name) }}
    WHERE created_at >= CURRENT_DATE - INTERVAL '1 day'
)
SELECT
    '{{ model_name }}.{{ column_name }}' as check_target,
    CASE
        WHEN latest.latest_avg > stats.avg_val + 3 * stats.std_val THEN 'ANOMALY_HIGH'
        WHEN latest.latest_avg < stats.avg_val - 3 * stats.std_val THEN 'ANOMALY_LOW'
        WHEN latest.latest_count < stats.row_count / {{ lookback_days }} * 0.5 THEN 'LOW_VOLUME'
        WHEN stats.null_count > stats.row_count * 0.1 THEN 'HIGH_NULLS'
        ELSE 'OK'
    END as status,
    stats.*,
    latest.*
FROM stats, latest
WHERE CASE
    WHEN latest.latest_avg > stats.avg_val + 3 * stats.std_val THEN TRUE
    WHEN latest.latest_avg < stats.avg_val - 3 * stats.std_val THEN TRUE
    WHEN latest.latest_count < stats.row_count / {{ lookback_days }} * 0.5 THEN TRUE
    WHEN stats.null_count > stats.row_count * 0.1 THEN TRUE
    ELSE FALSE
END

    result = subprocess.run(
        ["dbt", "run", "--target", "prod"],
        capture_output=True, text=True
    )
    
    if result.returncode == 0:
        print("dbt run OK - aucune erreur")
        # Exécuter les tests de qualité
        test_result = subprocess.run(
            ["dbt", "test", "--target", "prod"],
            capture_output=True, text=True
        )
        if test_result.returncode != 0:
            diagnose_test_failures(test_result.stderr)
        return
    
    # Erreur : demander à Claude de diagnostiquer
    error_output = result.stderr[-3000:]  # Limiter la taille
    
    diagnosis = subprocess.run(
        ["claude", "-p", f"""Le pipeline dbt a échoué. Voici l'erreur :

{error_output}

Diagnostique le problème et propose une solution :
1. Type d'erreur (schema change, permission, timeout, data issue)
2. Modèle concerné
3. Cause probable
4. Action corrective
5. Est-ce que la correction peut être appliquée automatiquement ? (oui/non)

Si oui, génère le correctif (SQL ou YAML).
Format : JSON avec les champs ci-dessus.""",
        "--output-format", "json"],
        capture_output=True, text=True
    )
    
    diag = json.loads(diagnosis.stdout)
    
    if diag.get("auto_fixable"):
        print(f"Correction automatique : {diag['action']}")
        # Appliquer le correctif
        apply_fix(diag)
        # Re-run dbt
        retry = subprocess.run(
            ["dbt", "run", "--select", diag["model"], "--target", "prod"],
            capture_output=True, text=True
        )
        if retry.returncode == 0:
            print("Pipeline réparé automatiquement")
            notify_slack(f"Pipeline réparé auto : {diag['action']}")
        else:
            escalate(diag, retry.stderr)
    else:
        escalate(diag, error_output)

    """Applique une correction automatique."""

        "priority": ticket["priority"],
        "requester_id": ticket["requester_id"],

"""
Audit trail pour toutes les actions de Claude Code.
Chaque appel d'outil est loggé avec : timestamp, outil, input, output,
utilisateur, session, durée, statut.
"""
import json
import sys
import hashlib
from datetime import datetime, timezone

def log_action(tool_name: str, tool_input: str, tool_output: str):
    """Enregistre une action dans l'audit trail."""
    
    # Masquer les données sensibles
    sanitized_input = mask_pii(tool_input)
    sanitized_output = mask_pii(tool_output)
    
    entry = {
        "timestamp": datetime.now(timezone.utc).isoformat(),
        "tool": tool_name,
        "input_hash": hashlib.sha256(tool_input.encode()).hexdigest()[:16],
        "input_preview": sanitized_input[:500],
        "output_preview": sanitized_output[:500],
        "session_id": get_session_id(),
        "user": get_current_user(),
        "status": "success" if "error" not in tool_output.lower() else "error",
        "data_classification": classify_data_level(tool_name, tool_input)
    }
    
    # Écrire dans le fichier d'audit (append-only)
    with open("/var/log/claude-audit/audit.jsonl", "a") as f:
        f.write(json.dumps(entry) + "\n")
    
    # Si données CONFIDENTIELLES : alerte immédiate
    if entry["data_classification"] == "CONFIDENTIEL":
        send_security_alert(entry)


def mask_pii(text: str) -> str:
    """Masque les données personnelles dans les logs."""
    import re
    # Emails
    text = re.sub(r'[\w.-]+@[\w.-]+\.\w+', '[EMAIL_MASKED]', text)
    # Téléphones
    text = re.sub(r'\b\d{2}[\s.-]?\d{2}[\s.-]?\d{2}[\s.-]?\d{2}[\s.-]?\d{2}\b', 
                  '[PHONE_MASKED]', text)
    # IBAN
    text = re.sub(r'\b[A-Z]{2}\d{2}[\s]?[\dA-Z]{4}[\s]?[\dA-Z]{4}[\s]?[\dA-Z]{4}', 
                  '[IBAN_MASKED]', text)
    # SSN / SIRET
    text = re.sub(r'\b\d{3}[\s.-]?\d{3}[\s.-]?\d{3}[\s.-]?\d{3,5}\b', 
                  '[ID_MASKED]', text)
    return text


def classify_data_level(tool_name: str, tool_input: str) -> str:
    """Classifie le niveau de sensibilité de l'opération."""
    confidential_tools = ["hr_salary", "hr_personal", "legal_contract", "treasury_transfer"]
    restricted_tools = ["accounting", "support_customer", "hr_recruitment"]
    
    for t in confidential_tools:
        if t in tool_name.lower():
            return "CONFIDENTIEL"
    for t in restricted_tools:
        if t in tool_name.lower():
            return "RESTREINT"
    return "INTERNE"

La plus grosse erreur : automatiser sans avoir mesuré le baseline. Avant chaque projet d'automatisation, mesurez précisément le temps passé, le coût, le taux d'erreur et la satisfaction. C'est la seule façon de prouver le ROI après déploiement et de justifier l'extension à d'autres départements.
