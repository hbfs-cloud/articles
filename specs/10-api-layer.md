# PRD-10: Public API Layer

## Overview

Static JSON API generated by `tools/gen-api.js`. Reads scanner status snapshots and writes flat
JSON files to `portfolio/v1/`. Serves 54 per-mode endpoints + 3 global endpoints.
Generated after every scanner run as part of the daily pipeline.

---

## 1. Base URL & Directory

```
https://articles.dailytickers.com/portfolio/v1/
Local:  {ROOT}/portfolio/v1/
```

Generated by: `node tools/gen-api.js`
Source snapshot: `scanner/status/history/{latest}.json`

---

## 2. Modes

Six modes, read dynamically from `data/modes-config.json`:

| Mode | Label | Color | Risk Profile | `minScore` | `filterName` | `topN` | `tklPoolEnabled` |
|---|---|---|---|---|---|---|---|
| `turbo` | Turbo | `#f59e0b` | Extreme | 90 | `all` | 1 | true |
| `dynamic` | Dynamic | `#dc2626` | High | 85 | `breakout_only` | 1 | false |
| `balanced` | Balanced | `#2563eb` | Moderate | 88 | `momentum_only` | 3 | true |
| `secured` | Secured | `#16a34a` | Low | 85 | `low_vol` | 3 | false |

## 4. JSON Schemas

### 4.1 `signals.json`

```json
{
  "updatedAt": "2026-05-07T08:57:10.198Z",
  "date": "2026-05-07",
  "mode": "balanced",
  "signals": [
    {
      "ticker": "GOOGL",
      "score": 95,
      "strategy": "Momentum",
      "entry": 381.00,
      "stop": 368.00,
      "tp1": 401.00,
      "tp2": 415.00,
      "rr": "1:1.5",
      "sharia": true,
      "thesis": "Q1 2026 earnings blowout: EPS $5.11 (+81% YoY)..."
    }
  ],
  "meta": {
    "minScore": 88,
    "filterName": "momentum_only",
    "topN": 3,
    "tklPoolEnabled": true,
    "configVersion": "v5.2-20260501",
    "regime": "RISK-ON"
  }
}
```

**Filtering logic** (applied in `signalsFor(cfg)` within `gen-status-page.js`, results consumed by `gen-api.js`):
1. Start with all signals from latest scanner snapshot.
2. Filter: `signal.score >= cfg.minScore`.
3. If `cfg.filterName !== 'all'`: apply strategy filter matching `cfg.filterName`.
   - `breakout_only` → keep only `strategy` matching `/breakout/i`
   - `momentum_only` → keep only `strategy` matching `/momentum/i`
   - `low_vol` → keep only signals with `atr_rank < 0.4`
   - `defensive` → keep only signals with `beta < 0.8`
   - `tkl_curated` → use TKL pool if `cfg.tklPoolEnabled === true`, else use main pool
4. Take `topN` highest-scoring signals.
5. If `tklPoolEnabled === true`: merge TKL pool signals (score derived from R/R + strategy) into candidate pool before topN selection.

**TKL score derivation** (for signals from `tkl_pool` source):
```javascript
const rr = (tp1 - entry) / Math.max(1e-6, entry - stop);
const stratBonus = { breakout: 4, momentum: 4, pre_squeeze: 3, pullback: 2, short_squeeze: 2 }[strat] ?? 2;
const rrBonus = Math.min(6, Math.max(0, (rr - 1.5) * 4));
score = Math.min(95, Math.round(85 + stratBonus * 0.4 + rrBonus));
```

## 5. Data Sources

| Source File | Used For |
|---|---|
| `scanner/status/history/{latest}.json` | Primary snapshot — signals, positions, orders |
| `data/backtest-results.json` | `frozen_{mode}` stats (authoritative equity/WR/PF/DD) |
| `data/backtest-trades.json` | Trade history per mode |
| `data/scanner-positions.json` | Open positions (live tracking state) |
| `data/modes-config.json` | Mode parameters, version, regime label |
| `data/risk-snapshots.json` | VaR, stress, correlation (from refresh-risk-metrics.js) |
| `scanner/status/history/*.json` | Historical equity curve points (one per snapshot date) |

**Load order in `gen-api.js`**:
1. Read `data/modes-config.json` → extract `modesConfigMeta` (`configVersion`, `regime`).
2. Read `data/risk-snapshots.json` → `riskSnap` (no-op if missing).
3. Scan `scanner/status/history/` → sort, pick latest `.json` file as `latestFile`.
4. Parse snapshot → `snap`. Detect `ordersStale` via `snap.scanDir vs todayKey`.
5. For each mode in `snap.modes`: call `writeMode(mode, modeId)`.

## 6. Generation Script Contract

```javascript
// tools/gen-api.js entry point
function writeMode(modeData, modePrefix) {
  // modeData: parsed from snapshot.modes[modeId]
  // modePrefix: e.g. 'balanced' → writes to portfolio/v1/balanced/
  write(`${modePrefix}/signals.json`,         buildSignals(modeData, modePrefix));
  write(`${modePrefix}/positions.json`,        buildPositions(modeData, modePrefix));
  write(`${modePrefix}/equity.json`,           buildEquity(modeData, modePrefix));
  write(`${modePrefix}/orders.json`,           buildOrders(modeData, modePrefix));
  write(`${modePrefix}/actions.json`,          buildActions(modeData, modePrefix));
  write(`${modePrefix}/trades.json`,           buildTrades(modeData, modePrefix));
  write(`${modePrefix}/risk.json`,             buildRisk(modeData, modePrefix));
  write(`${modePrefix}/winning-streaks.json`,  buildStreaks(modeData, modePrefix));
  write(`${modePrefix}/all.json`,              buildAll(modeData, modePrefix));
}

function write(filename, content) {
  const outPath = path.join(OUT, filename);
  fs.mkdirSync(path.dirname(outPath), { recursive: true });
  fs.writeFileSync(outPath, JSON.stringify(content, null, 2));
}
```

Root backward-compat endpoints: call `writeMode(snap.modes['balanced'], '')` after per-mode writes.

## 7. Cache & Freshness

- Files are static JSON — no server-side caching headers (GitHub Pages defaults).
- Consumers should treat `updatedAt` as freshness indicator.
- `ordersStale: true` in `orders.json` signals that the scan has not yet run for today.
- Expected update frequency: once per day after scanner pipeline completes (~23h NY time weekdays).

## 11. Report Generation

Async endpoint for generating formatted reports (PDF/HTML) from analytics data.

### 11.1 Endpoint

```
POST /portfolio/v1/reports/generate
```

### 11.2 Request schema

```json
{
  "type": "daily_pnl" | "weekly_digest" | "monthly_review",
  "mode": "balanced",
  "period": { "from": "2026-05-01", "to": "2026-05-07" },
  "format": "json" | "html",
  "include_charts": true
}
```

### 11.3 Response

Synchronous for `json` format (< 2s). Returns `202` with `job_id` for `html` format.

```json
{
  "report_id": "rpt-20260507-balanced-weekly",
  "type": "weekly_digest",
  "format": "json",
  "generated_at": "2026-05-07T23:30:00Z",
  "download_url": "/portfolio/v1/balanced/reports/weekly-2026-W19.json",
  "content": { "..." : "..." }
}
```

### 11.4 Storage

```
portfolio/v1/{mode}/reports/daily-{YYYY-MM-DD}.json
portfolio/v1/{mode}/reports/weekly-{YYYY-Www}.json
portfolio/v1/{mode}/reports/monthly-{YYYY-MM}.json
portfolio/v1/reports/latest.json
```

`latest.json` contains pointers to the most recent report of each type:
```json
{
  "daily":   { "url": "/portfolio/v1/balanced/reports/daily-2026-05-07.json", "date": "2026-05-07" },
  "weekly":  { "url": "/portfolio/v1/balanced/reports/weekly-2026-W19.json", "week": "2026-W19" },
  "monthly": { "url": "/portfolio/v1/balanced/reports/monthly-2026-04.json", "month": "2026-04" }
}
```
