Why AI Completes the Terminal

The Missing Layer — AI for Pattern Recognition and Synthesis

Your terminal already has data, signals, and visualization. But there's a gap between seeing data and understanding it. That gap is narrative synthesis — the ability to look at 50 data points and say "this is a risk-off rotation driven by yield curve inversion, with tech showing relative strength due to flight-to-quality."

Humans are slow at this. AI is fast. Claude can read your entire watchlist's technical profile, cross-reference macro data, check news sentiment, and produce a structured market assessment in under 10 seconds. That's the AI layer.

Pattern Recognition

AI spots complex multi-factor patterns that simple indicators miss: sector rotation, relative strength shifts, regime changes.

News Synthesis

Reads 100 headlines, extracts market-moving information, assesses impact. Replaces 30 minutes of manual reading.

Risk Assessment

Portfolio Greeks, correlation matrix, VaR — AI interprets numbers and flags hidden concentration risks in plain English.

Morning Briefings

Automated pre-market briefing delivered to Telegram at 7 AM: overnight moves, macro events, earnings, signals to watch.

Claude API Integration

Structured Prompts for Market Analysis

The key to reliable AI output is structured prompting. You provide the data explicitly in the prompt, define the exact output format, and constrain the model to only use the data you gave it.

Python — Claude API Market Analysis import anthropic client = anthropic.Anthropic() # uses ANTHROPIC_API_KEY env var async def analyze_stock(symbol: str, data: dict) -> dict: """Generate institutional-quality stock analysis.""" prompt = f"""Analyze {symbol} using ONLY the following data. Do not use any information from your training data — only what is provided below. ## Market Data - Current Price: ${data['price']} - 52-Week High: ${data['high_52w']} | Low: ${data['low_52w']} - RSI(14): {data['rsi']} - MACD Histogram: {data['macd_hist']} - Volume vs 20d Avg: {data['vol_ratio']}x - Above EMA 200: {data['above_ema200']} - ATR(14): ${data['atr']} ({data['atr_pct']}% of price) ## Fundamentals - Market Cap: ${data['market_cap']} - P/E: {data['pe']} | Forward P/E: {data['fwd_pe']} - Revenue Growth (YoY): {data['rev_growth']}% - Free Cash Flow: ${data['fcf']} - Insider Activity (90d): {data['insider_summary']} ## Recent News {data['news_headlines']} ## Instructions Provide analysis in this exact JSON format: {{ "summary": "2-3 sentence executive summary", "technical_view": "bullish|neutral|bearish", "fundamental_view": "strong|moderate|weak", "key_levels": {{"support": price, "resistance": price}}, "catalysts": ["upcoming catalyst 1", "catalyst 2"], "risks": ["risk 1", "risk 2"], "confidence": 1-10, "trade_idea": {{ "direction": "long|short|none", "entry": price, "stop": price, "target": price, "rationale": "1-2 sentences" }} }}""" response = client.messages.create( model="claude-sonnet-4-20250514", max_tokens=2000, messages=[{"role": "user", "content": prompt}], temperature=0.3, # Low temp for factual output ) return json.loads(response.content[0].text)

MCP Server — Exposing Your Data

Building an MCP Server for Your Terminal

MCP (Model Context Protocol) is the bridge between Claude and your database. Instead of pasting data into prompts manually, MCP lets Claude call your tools directly — querying your database, running your screeners, and accessing live quotes in real-time.

Python — Full MCP Server Implementation from mcp.server import Server from mcp.types import Tool, TextContent import json server = Server("trading-terminal-mcp") @server.tool() async def get_market_overview() -> list[TextContent]: """Get snapshot of major indices, crypto, commodities, rates.""" overview = await db.get_market_snapshot() return [TextContent(type="text", text=json.dumps(overview, default=str))] @server.tool() async def query_data( symbols: str, data_types: str, period: str = "3M" ) -> list[TextContent]: """Query market data. Types: quote, bars_daily, technicals, financials, earnings, sentiment, news, insider_transactions.""" results = {} for sym in symbols.split(","): sym_data = {} for dtype in data_types.split(","): sym_data[dtype] = await db.query(sym.strip(), dtype.strip(), period) results[sym.strip()] = sym_data return [TextContent(type="text", text=json.dumps(results, default=str))] @server.tool() async def run_screener( strategy: str, universe: str = "SP500", max_results: int = 10 ) -> list[TextContent]: """Run a predefined screening strategy. Strategies: oversold_bounce, momentum_breakout, mean_reversion, earnings_surprise, insider_buying.""" results = await screener.run_strategy(strategy, universe, max_results) return [TextContent(type="text", text=json.dumps(results, default=str))] @server.tool() async def get_portfolio() -> list[TextContent]: """Get current portfolio positions with P&L and risk metrics.""" portfolio = await db.get_portfolio() return [TextContent(type="text", text=json.dumps(portfolio, default=str))] # Run the MCP server if __name__ == "__main__": import asyncio from mcp.server.stdio import stdio_server asyncio.run(stdio_server(server))

MCP Server Configuration

Add your MCP server to Claude Desktop's config (claude_desktop_config.json) or Claude Code's MCP settings. Claude will automatically discover your tools and use them when analyzing markets. The key advantage: Claude decides what data to fetch based on the question — you don't need to pre-load everything.

Automated Morning Briefings

The AI-Powered Morning Briefing Pipeline

Every morning at 7 AM, your terminal should deliver a structured briefing to your phone. Here's the pipeline:

Python — Automated Morning Briefing Generator class MorningBriefing: """Generate and deliver daily morning briefing.""" def __init__(self, ai_client, db, alert_service): self.ai = ai_client self.db = db self.alerts = alert_service async def generate(self) -> str: # 1. Collect all data market = await self.db.get_market_snapshot() signals = await self.db.get_latest_signals() portfolio = await self.db.get_portfolio() calendar = await self.db.get_economic_calendar() news = await self.db.get_overnight_news(limit=20) # 2. Ask Claude to synthesize prompt = f"""Generate a concise morning market briefing using ONLY the following data. Format as Telegram Markdown. ## Market Snapshot {json.dumps(market, indent=2)} ## Active Signals {json.dumps(signals, indent=2)} ## Portfolio (Open Positions) {json.dumps(portfolio, indent=2)} ## Economic Calendar Today {json.dumps(calendar, indent=2)} ## Overnight News {json.dumps(news, indent=2)} ## Format 1. One-line market mood (emoji + 5 words max) 2. Key overnight moves (3 bullets) 3. Today's calendar events (ranked by impact) 4. Signal alerts (new signals from screener) 5. Portfolio check (positions to watch) 6. Risk flags (anything unusual) Keep it under 2000 chars for Telegram.""" response = self.ai.messages.create( model="claude-sonnet-4-20250514", max_tokens=1500, messages=[{"role": "user", "content": prompt}], temperature=0.2, ) return response.content[0].text async def deliver(self): briefing = await self.generate() await self.alerts.send_telegram(briefing) await self.alerts.send_discord(briefing, channel="morning-briefing")
Sentiment Analysis

News Headlines and Social Media Pulse

Sentiment analysis is one of the most valuable AI applications in trading. The idea: score news headlines and social media posts on a bullish-to-bearish scale, then aggregate scores per symbol to get a sentiment signal.

Python — Batch Headline Sentiment Scorer async def score_headlines( headlines: list[dict], client: anthropic.Anthropic ) -> list[dict]: """Score a batch of headlines for market sentiment. Returns list of {headline, symbol, score, reasoning}. Score: -1.0 (very bearish) to +1.0 (very bullish). """ headlines_text = "\n".join( f"{i+1}. [{h['symbol']}] {h['title']}" for i, h in enumerate(headlines) ) prompt = f"""Score each headline for market sentiment impact. Return a JSON array with one object per headline. Headlines: {headlines_text} For each headline, return: - "index": headline number - "score": float from -1.0 (very bearish) to +1.0 (very bullish) - "impact": "high", "medium", or "low" - "reasoning": one sentence explaining the score Only consider impact on the stock price. Ignore neutral news (score 0). Return ONLY valid JSON array, no markdown.""" response = client.messages.create( model="claude-sonnet-4-20250514", max_tokens=2000, messages=[{"role": "user", "content": prompt}], temperature=0.1, ) scores = json.loads(response.content[0].text) # Merge scores back with original headlines for s in scores: idx = s["index"] - 1 headlines[idx]["sentiment_score"] = s["score"] headlines[idx]["sentiment_impact"] = s["impact"] return headlines
Anti-Hallucination Techniques

Grounding AI Output in Real Data

The #1 risk of using AI for trading analysis is hallucination — the model inventing facts, prices, or events that don't exist. Here are the techniques to eliminate this:

TechniqueHow It WorksEffectiveness
Data injectionAll data provided explicitly in the prompt. Model told to use ONLY provided data.Very High
Low temperatureTemperature 0.1-0.3 reduces creative output, increases factual adherence.High
Structured outputJSON schema forces model to fill specific fields, no free-form text.High
MCP toolsModel fetches data via tools instead of relying on memory. Real-time grounding.Very High
Post-validationCompare AI-generated prices/dates against your database. Flag discrepancies.Very High
Confidence scoringModel rates its own confidence 1-10. Discard analyses below 6.Medium

The Golden Rule

Never let AI output directly trigger a trade. AI generates analysis and suggestions. A human (you) makes the decision. Even with perfect grounding, AI can misinterpret context. Use it as a highly intelligent research assistant, not an autopilot.
