Dashboard Framework Choices

Choosing Your Dashboard Stack

The dashboard is what you interact with every day. It needs to be fast, responsive, and information-dense — showing the maximum amount of data with the minimum cognitive load.

Our Recommendation: Express + ECharts

For a personal trading terminal, Express.js + static HTML + ECharts is the sweet spot. You get full control over every pixel, native WebSocket support, sub-100ms renders, and it's dead simple to deploy. Streamlit is great for prototyping, but its polling model and limited customization make it frustrating for daily use. Save React/Next.js for when you want to build a SaaS product for others.

WebSocket Live Updates

Real-Time Data Flow

The magic of a live dashboard is server-push. Instead of the browser polling every second, the server pushes updates only when data changes. Here's the client-side WebSocket handler:

JavaScript — WebSocket Client with Auto-Reconnect class LiveConnection { constructor(url) { this.url = url; this.handlers = new Map(); this.reconnectDelay = 1000; this.maxDelay = 30000; this.connect(); } connect() { this.ws = new WebSocket(this.url); this.ws.onopen = () => { console.log('Connected to terminal'); this.reconnectDelay = 1000; // Reset backoff document.getElementById('status').className = 'connected'; }; this.ws.onmessage = (event) => { const msg = JSON.parse(event.data); const handler = this.handlers.get(msg.type); if (handler) handler(msg.data); }; this.ws.onclose = () => { document.getElementById('status').className = 'disconnected'; setTimeout(() => { this.reconnectDelay = Math.min(this.reconnectDelay * 1.5, this.maxDelay); this.connect(); }, this.reconnectDelay); }; } on(type, handler) { this.handlers.set(type, handler); } } // Usage const live = new LiveConnection('ws://localhost:3000'); live.on('quote', (data) => updateWatchlistRow(data)); live.on('signal', (data) => showSignalAlert(data)); live.on('news', (data) => appendNewsTicker(data));
Multi-Channel Alert System

Alerts via Telegram, Discord, Email

You can't watch the dashboard 24/7. The alert system monitors your signals and pushes notifications when something important happens. Here are the three channels you should set up:

Telegram Bot

Instant push notifications on your phone. Best for time-sensitive alerts (breakouts, stops hit). 4,096 char messages with Markdown.

Discord Webhook

Rich embeds with charts, tables, color-coded urgency. Best for morning briefings and daily scanner results. Searchable history.

Email (SMTP)

Weekly summaries, portfolio reports, compliance records. Not real-time, but permanent record. Use SendGrid or SES.

Python — Telegram Alert Service import httpx class TelegramAlert: """Send trading alerts via Telegram bot.""" def __init__(self, bot_token: str, chat_id: str): self.base = f"https://api.telegram.org/bot{bot_token}" self.chat_id = chat_id async def send(self, message: str, urgent: bool = False): """Send a Markdown-formatted alert.""" prefix = "*ALERT*" if urgent else "Signal" async with httpx.AsyncClient() as client: await client.post( f"{self.base}/sendMessage", json={ "chat_id": self.chat_id, "text": f"{prefix}: {message}", "parse_mode": "Markdown", "disable_notification": not urgent, } ) async def send_signal(self, signal: dict): """Format and send a trading signal alert.""" emoji = "BUY" if signal["direction"] == "long" else "SELL" msg = ( f"*{emoji} {signal['symbol']}*\n" f"Score: {signal['score']}/100 ({signal['grade']})\n" f"Entry: ${signal['entry']:.2f}\n" f"Stop: ${signal['stop']:.2f}\n" f"Target: ${signal['target']:.2f}\n" f"R/R: {signal['rr']:.1f}x" ) await self.send(msg, urgent=signal["score"] >= 85)

Dashboard Design Principles

Three rules for effective trading dashboards: (1) Information density — show more data per pixel, less whitespace, no decorative elements. (2) Color = signal — green/red only for P&L; use blue/gray for neutral data. Never use color for decoration. (3) Hierarchy — the most important number (total P&L) should be the biggest thing on the screen. Secondary data (individual positions) smaller. Tertiary data (risk metrics) smallest.

Key Takeaways

Key Takeaways — Part 4

  • Express.js + ECharts is the optimal stack for a personal trading dashboard: full control, native WebSocket, fast renders.
  • Market heatmaps (treemap) give instant visual snapshots of sector/market health.
  • ECharts candlestick with EMA overlays and volume subplot replicates TradingView's core functionality.
  • WebSocket with auto-reconnect and exponential backoff keeps the dashboard live without polling overhead.
  • Multi-channel alerts (Telegram for urgent, Discord for daily briefings, email for records) ensure you never miss a signal.
  • Portfolio tracking with real-time P&L, sector exposure pie chart, and risk metrics completes the terminal experience.
