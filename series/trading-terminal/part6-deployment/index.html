Monitoring & Alerting

Keeping the Lights On

A terminal that goes down on a volatile day is worse than no terminal. You need monitoring at three levels:

Uptime Monitoring

External ping every 60s. UptimeRobot (free) or Better Stack ($10/mo). Alert via Telegram if dashboard goes down.

Data Freshness

Check that bars_daily was updated within the last 24h. Alert if stale data detected. Prevents trading on old prices.

Error Alerting

Log all errors to a rotating file. Alert on >5 errors/hour or any critical failure (DB down, API key expired).

Python — Health Check Endpoint from datetime import datetime, timedelta async def health_check() -> dict: """Comprehensive health check for all services.""" checks = {} # 1. Database connectivity try: await db.execute("SELECT 1") checks["database"] = "ok" except: checks["database"] = "FAIL" # 2. Redis connectivity try: await cache.redis.ping() checks["redis"] = "ok" except: checks["redis"] = "FAIL" # 3. Data freshness latest = await db.get_latest_bar_timestamp() stale = (datetime.utcnow() - latest) > timedelta(hours=26) checks["data_fresh"] = "STALE" if stale else "ok" # 4. Disk space disk = shutil.disk_usage("/") pct_free = disk.free / disk.total * 100 checks["disk"] = "LOW" if pct_free < 10 else "ok" # 5. Overall status checks["status"] = "healthy" if all( v == "ok" for v in checks.values() if v != checks["status"] ) else "degraded" return checks
Security

API Key Management and Access Control

Your terminal handles API keys worth money and potentially trading credentials. Security is not optional.

API key leak.env file + Docker secrets.gitignore on day 1, rotate quarterly
Dashboard exposureCaddy + HTTP auth or Cloudflare TunnelPassword-protect dashboard, no public access
DB accessNetwork isolationDB only accessible from Docker network, never expose port 5432
SSH bruteforceKey-only auth + fail2banDisable password SSH, install fail2ban
Supply chainPin Docker image versionsUse image:tag@sha256:hash for critical services

The .env Checklist

Your .env file should contain: database password, Yahoo cookie, Alpha Vantage key, Polygon API key, Anthropic API key, Telegram bot token + chat ID, Discord webhook URL. Back it up offline (encrypted USB or password manager). If your VPS dies, you need these keys to redeploy in minutes, not hours.

When to Upgrade Your VPS

Monitor RAM usage. When TimescaleDB + Redis + all services consistently use >75% of your RAM, upgrade to the next tier. On Hetzner, going from CX31 (8 GB) to CX41 (16 GB) is $15.90/month — still 99% cheaper than Bloomberg. You won't need this until you're running 1,000+ symbols with real-time streaming.

  • Deploy on Hetzner CX31 ($8.50/mo) — best value for 8 GB RAM, NVMe, US East location.
